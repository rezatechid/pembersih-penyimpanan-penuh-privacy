1. Tentang aplikasi

Pembersih Penyimpanan Penuh (nama Inggris: Storage Cleaner & File Tools; ID paket com.pembersihpenyimpananpenuh.app) dikembangkan oleh reza tech. Aplikasi membantu pengguna memeriksa kapasitas penyimpanan, meninjau file atau folder yang terdeteksi, serta melakukan tindakan pembersihan yang didukung Android dan diizinkan pengguna.

Fungsi pemeriksaan file dan pembersihan utama diproses secara lokal pada perangkat. Aplikasi tidak memiliki server pengunggahan file pribadi milik pengembang. Namun, aplikasi menggunakan layanan pihak ketiga untuk iklan dan pengelolaan persetujuan, sebagaimana dijelaskan di bawah.

2. Data dan akses yang digunakan

  • File dan metadata penyimpanan: bila pengguna memberikan izin, aplikasi dapat membaca nama, jenis, ukuran, lokasi, informasi waktu, dan pratinjau file yang dapat diakses untuk pemindaian, pencarian duplikat, analisis penyimpanan, pengelolaan file, dan peninjauan sebelum pembersihan. Isi foto/video/dokumen dapat dibuka secara lokal saat pengguna meminta pratinjau.
  • Informasi aplikasi dan penggunaan penyimpanan: fitur terkait dapat menggunakan informasi aplikasi yang tersedia melalui API Android dan, bila diberikan, izin akses penggunaan (Usage Access) untuk memperlihatkan statistik aplikasi/cache. Aplikasi tidak menganggap cache pribadi aplikasi lain otomatis dapat dihapus.
  • Preferensi dan riwayat lokal: bahasa/tampilan, pengecualian, pilihan fitur, dan catatan hasil pembersihan dapat disimpan pada perangkat untuk menjalankan fungsi aplikasi.
  • Data iklan: Google Mobile Ads SDK/AdMob dan mekanisme persetujuan Google dapat memproses data perangkat dan interaksi, sebagaimana dijelaskan pada bagian 4.

3. Tujuan penggunaan data

Data lokal dipakai untuk menampilkan hasil pemindaian, mengelompokkan kandidat, membuat pratinjau, menjaga pilihan dan pengecualian, mengonfirmasi tindakan yang diminta pengguna, serta melaporkan hasil operasi yang benar-benar berhasil. File yang terdeteksi sebagai Perlu diperiksa atau Dilindungi tidak otomatis memenuhi syarat penghapusan. Aplikasi tidak menjamin semua cache sistem atau data privat aplikasi lain dapat dibersihkan.

4. Iklan, Google AdMob, dan persetujuan

Aplikasi menggunakan Google AdMob (Google Mobile Ads SDK) untuk menampilkan iklan dan Google User Messaging Platform (UMP) untuk mengelola informasi atau pilihan persetujuan bila diperlukan. Saat layanan iklan dijalankan, Google dapat mengumpulkan atau menerima alamat IP (yang dapat digunakan untuk memperkirakan lokasi umum), interaksi dengan aplikasi/iklan, informasi diagnostik, pengenal iklan, dan pengenal perangkat/aplikasi lain yang berlaku. Data tersebut dapat digunakan untuk penayangan iklan, pengukuran, analisis, keamanan, dan pencegahan penipuan, sesuai pengaturan dan pilihan persetujuan yang berlaku.

Praktik pihak ketiga dapat berbeda menurut wilayah, versi SDK, dan pilihan privasi. Aplikasi tidak mengirimkan isi foto, video, dokumen, atau daftar file pribadi ke pengembang untuk penayangan iklan. Penanganan data oleh Google tunduk pada kebijakan Google, termasuk Kebijakan Privasi Google dan pengungkapan data Google Mobile Ads SDK. Pengguna dapat mengelola pilihan iklan/privasi yang tersedia melalui dialog persetujuan aplikasi dan pengaturan perangkat.

5. Izin Android

  • Akses semua file (MANAGE_EXTERNAL_STORAGE), bila diminta dan diberikan pada Android yang mendukung: membantu pemeriksaan serta pengelolaan file pada penyimpanan bersama yang dapat diakses secara sah. Izin ini tidak memberikan akses bebas ke seluruh data privat aplikasi lain.
  • Akses media, penyimpanan, dan/atau pemilih dokumen: memungkinkan pengguna memilih atau melihat item sesuai versi Android dan izin yang diberikan, termasuk melalui Storage Access Framework.
  • Akses penggunaan (Usage Access), jika diaktifkan secara terpisah oleh pengguna: diperlukan bagi statistik penggunaan penyimpanan/cache aplikasi yang didukung.
  • Internet dan status jaringan: digunakan untuk iklan, permintaan persetujuan, dan membuka halaman kebijakan privasi melalui browser; pemindaian file inti tidak membutuhkan koneksi internet.

Pengguna dapat menolak atau mencabut izin melalui Pengaturan Android. Fitur tertentu mungkin menjadi terbatas, dan pemindaian yang tidak lengkap tidak boleh ditampilkan seolah-olah lengkap.

6. Berbagi data dan layanan eksternal

Pengembang tidak mengoperasikan server untuk menerima atau menyimpan file pribadi yang dipindai. Data yang diproses SDK iklan dapat dikirim kepada Google sesuai bagian 4. Jika pengguna membuka dokumen dari penyedia penyimpanan atau aplikasi pihak ketiga, kebijakan dan izin penyedia tersebut dapat berlaku. Halaman kebijakan privasi ini dihosting melalui GitHub Pages; kunjungan ke situs dapat diproses oleh penyedia hosting, misalnya melalui log teknis dan alamat IP.

7. Penyimpanan dan penghapusan data

Metadata pemindaian dapat digunakan selama sesi aplikasi, sedangkan preferensi, pengecualian, atau riwayat pembersihan dapat tersimpan secara lokal hingga dihapus melalui fitur yang tersedia, data aplikasi dihapus melalui Pengaturan Android, atau aplikasi di-uninstall (sesuai perilaku cadangan sistem/perangkat). Penghapusan file pengguna hanya dilakukan melalui alur yang diizinkan dan dikonfirmasi; beberapa file tidak dapat dihapus oleh aplikasi karena batasan Android atau perlindungan keamanan. Riwayat dan pengenal yang ditangani Google mengikuti kebijakan penyimpanan Google, bukan dikendalikan langsung oleh aplikasi ini.

8. Keamanan

Pemeriksaan file dilakukan menggunakan akses dan izin Android yang tersedia. Aplikasi menerapkan pemisahan antara kandidat yang bisa dipertimbangkan untuk penghapusan dan item yang belum terverifikasi. Kami berupaya membatasi pemrosesan serta akses pada kebutuhan fungsi, tetapi tidak dapat menjamin keamanan absolut perangkat maupun layanan pihak ketiga.

9. Pilihan dan hak pengguna

Pengguna dapat mengelola izin file, media, akses penggunaan, dan preferensi iklan dari aplikasi atau Pengaturan Android. Untuk menghapus data lokal aplikasi, gunakan opsi yang tersedia atau hapus data aplikasi melalui sistem Android. Untuk pertanyaan mengenai privasi atau permintaan terkait data yang dikelola pengembang, hubungi kontak di bawah. Pertanyaan terkait data iklan yang dikendalikan Google juga dapat ditangani melalui kontrol privasi Google.

10. Perubahan kebijakan

Kebijakan ini dapat diperbarui jika fungsi aplikasi, penyedia SDK, atau ketentuan hukum berubah. Tanggal pembaruan akan dicantumkan pada halaman ini.
