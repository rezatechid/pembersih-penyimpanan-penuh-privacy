1. Tentang aplikasi dan pengelola

Nama Indonesia: Pembersih Penyimpanan Penuh. Nama Inggris: Storage Cleaner & File Tools.

Pembersih Penyimpanan Penuh membantu Anda melihat penggunaan partisi data internal Android, membersihkan file sementara tertentu milik aplikasi, dan mengelola file yang Anda pilih melalui pemilih dokumen Android.

2. Informasi yang diproses

Informasi · Tujuan dan cara pemrosesan

Total, tersedia, dan terpakai pada partisi data internal
Dibaca melalui StatFs untuk menampilkan statistik. Angka ini bukan jaminan kapasitas fisik keseluruhan perangkat. Tidak memerlukan pembacaan semua file.
URI, nama, ukuran, tipe MIME, ketersediaan dan kemampuan hapus file pilihan
Diperoleh dari provider dokumen Android untuk menampilkan, mengurutkan dan memeriksa file yang Anda pilih. Ukuran yang tidak diberikan provider ditampilkan sebagai tidak diketahui. Nama file dapat mengandung informasi pribadi.
Centang pilihan, status, hasil penghapusan dan penguncian hasil belum terverifikasi
Dipakai dalam memori sesi untuk menjalankan pilihan Anda, menghitung hasil dan menghindari penghapusan ulang atas URI tersebut dalam sesi yang sama.
Metadata file sementara tertentu milik aplikasi
Digunakan untuk memvalidasi keamanan dan menghitung byte file yang benar-benar berhasil dihapus dalam cakupan pembersihan otomatis.
Preferensi tampilan
Kode aplikasi menggunakan DataStore lokal appearance, dengan kunci theme_mode untuk nilai sistem/terang/gelap. Versi saat ini membaca preferensi tersebut; tidak menyediakan halaman pengaturan tema terpisah.

Aplikasi membaca metadata file pilihan untuk membandingkan ukuran; kode fitur ini tidak membuka atau menyalin isi file tersebut untuk dianalisis. Aplikasi tidak menyediakan akun, login, iklan, analytics, atau pengiriman laporan crash ke server developer pada versi yang diaudit.

3. Akses file dan konfirmasi penghapusan

Pemilihan file menggunakan Storage Access Framework (SAF), yaitu pemilih dokumen resmi Android. Anda menentukan file yang diizinkan untuk diperiksa. Daftar dibatasi sampai 50 URI unik per pemilihan dan tidak otomatis mencentang file untuk dihapus.

Memilih file saja tidak menghapusnya. Penghapusan file pilihan memerlukan centang Anda dan konfirmasi di aplikasi; provider tertentu dapat meminta persetujuan tambahan dari Android. Aplikasi meminta provider menghapus dokumen melalui API resmi. Penghapusan dapat bersifat permanen sesuai perilaku provider dan tidak menyediakan pemulihan di aplikasi ini.

Jika hasil belum dapat diverifikasi, aplikasi tidak menghitungnya sebagai sukses atau gagal terkonfirmasi dan tidak memasukkan ukurannya ke byte terkonfirmasi. Penghapusan ulang atas URI yang sama dinonaktifkan sepanjang sesi ViewModel. Periksa keberadaan file secara manual melalui aplikasi Files sebelum mencoba kembali pada sesi berikutnya. Berakhirnya proses aplikasi menghilangkan laporan dan penguncian sesi, tetapi tidak membatalkan file yang sudah dihapus.

Aplikasi tidak memindai seluruh perangkat, tidak mengakses cache privat aplikasi lain, dan tidak menggunakan root, Accessibility Service atau izin akses semua file. Pembersihan otomatis hanya mencakup file sementara milik aplikasi yang memenuhi aturan keamanan. Foto, video, dokumen, musik dan Downloads tidak dipindai/dihapus oleh pembersihan otomatis. Jika Anda sendiri memilih dan mengonfirmasi penghapusan suatu file melalui SAF, termasuk file pribadi, penghapusan hanya ditujukan ke file pilihan tersebut.

4. Pengiriman dan pembagian informasi

Berdasarkan kode, konfigurasi, dan dependency runtime yang diperiksa pada versi ini, aplikasi tidak mengirim metadata/isi file, statistik penyimpanan, atau preferensi Anda ke server developer maupun layanan analytics/iklan. Tidak ada backend aplikasi atau izin INTERNET yang ditemukan pada konfigurasi yang diaudit.

Permintaan metadata dan penghapusan diteruskan ke provider dokumen yang dipilih melalui Android. Provider dapat berupa penyimpanan lokal atau layanan cloud milik pihak lain. Provider cloud dapat memakai koneksi internet dan memproses permintaan menurut kebijakannya sendiri; hal tersebut bukan janji bahwa semua aktivitas provider/Android berlangsung offline. Aplikasi ini tidak mengendalikan layanan cloud, cadangan, atau log sistem Android milik pihak lain.

Tombol KELOLA PENYIMPANAN ANDROID membuka pengaturan Android. Pengelolaan cache aplikasi lain di sana dilakukan manual oleh Anda.

5. Penyimpanan, retensi, dan penghapusan

Daftar file, metadata, centang, laporan dan penguncian penghapusan disimpan dalam memori ViewModel. Rotasi layar dapat mempertahankan sesi tersebut; mengganti pilihan atau berakhirnya sesi/proses dapat menghapus atau mengganti informasi. Aplikasi tidak membuat riwayat file permanen atau ledger penghapusan, dan tidak memanggil takePersistableUriPermission untuk mempertahankan izin SAF. Izin dan catatan yang dikelola Android/provider mengikuti perilaku sistem tersebut; kami tidak menjanjikan jangka waktu izin tertentu.

Preferensi tampilan yang tersimpan berada pada penyimpanan privat aplikasi sampai diubah oleh kode yang mendukungnya atau data aplikasi dihapus. Anda dapat menghapus data aplikasi atau mencopot aplikasi melalui pengaturan Android untuk menghapus data lokal aplikasi. Tindakan ini tidak memulihkan file yang sebelumnya sudah dihapus dan tidak menghapus file pribadi lain di luar data privat aplikasi.

Cache sementara dapat dibersihkan oleh Android. Tombol pembersihan aplikasi hanya menghapus file dalam cakupan aman yang diperbolehkan, bukan seluruh cache atau preferensi aplikasi.

Manifest memakai allowBackup=false untuk menonaktifkan backup aplikasi. Namun beberapa perangkat dapat tetap mentransfer data aplikasi saat migrasi antarperangkat. Karena belum ada aturan dataExtractionRules khusus dan pengujian migrasi belum dilakukan, kami tidak menjanjikan pencegahan semua transfer oleh sistem/OEM.

6. Keamanan dan kendali pengguna

Data preferensi memakai sandbox privat Android. Aplikasi memeriksa kembali metadata sebelum menghapus file pilihan. Pembersihan otomatis membatasi lokasi/nama file dan menolak symbolic link yang tidak aman. Kode produksi yang diperiksa tidak mencatat nama atau URI file ke log aplikasi; Android/provider dapat menghasilkan log sistem sendiri.

Anda dapat membatalkan pemilih dokumen atau dialog konfirmasi. Tidak ada pembersihan file pilihan otomatis saat aplikasi kembali dari Settings. Tidak ada penghapusan otomatis sebagai pengganti file yang gagal diproses. Tidak ada jaminan jumlah ruang yang akan bertambah; ukuran provider cloud atau keterlambatan statistik dapat memengaruhi hasil.

Untuk pertanyaan privasi atau dukungan, hubungi rezatech.id@gmail.com, atas nama reza tech. Jangan mengirim file pribadi, URI, atau log sensitif kecuali memang diperlukan dan Anda telah menyunting informasi pribadi.

Perubahan praktik pemrosesan data harus diikuti pembaruan kebijakan ini dan informasi Data safety.

8. Privasi pengunjung halaman GitHub Pages

Halaman statis ini tidak memuat tracker atau analytics. Ketika halaman di-host di GitHub Pages dan dikunjungi, GitHub mencatat serta menyimpan alamat IP pengunjung untuk keamanan, termasuk jika pengunjung tidak masuk ke GitHub.

Penanganan data hosting mengikuti Pernyataan Privasi GitHub. Hal ini tidak berarti aplikasi mengunggah file pilihan Anda ke GitHub.
